# Existential Engineering Company

We build things.

We make [Aureo](https://aureo.audio), a studio gear and plugin catalog for music producers.
It is offline-first: no account, and your data stays on your machine.

## Open source

- [**catalog**](https://github.com/existential-engineering/catalog): the open, CC0 catalog of
  synths, plugins and studio gear that Aureo matches against. Corrections and additions welcome.
